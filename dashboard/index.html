How expected value is scored

One function scores every protocol from the snapshot's own figures — TVL, 7-day growth, and how long it has run with no token. No protocol name is special-cased. The board ranks launch candidates by expected value = gross implied value × launch odds, and the verdict follows from the estimated airdrop value per farmer against the cost of the farm plan.

expected value = gross value × P(launch within 1 year | not launched yet)

An estimate, not a price. It says what a launch would be worth if the protocol's record stayed as it is; it does not predict whether or when a token is issued.

Method: a protocol is pre-token when the snapshot records no market cap, no CoinGecko id and no symbol for it. The board covers every protocol on the snapshot's watchlist and every other launch candidate — a pre-token protocol that is not a wrapped, staked or bridged product of a token that already trades. Derivatives and token-trading protocols are listed in their own views, so all 758 protocols in the snapshot are accounted for: the board, the derivatives and the already-trading list add up to the snapshot.

Assumptions, stated as assumptions: the verdict's farmer share is 10% of the token's value to farmers, a typical airdrop allocation; the farmer count is estimated from TVL (25 × the square root of TVL in millions, clamped to 100–5000). Both are documented in the model, and the verdict's threshold is three times the plan's cost.
