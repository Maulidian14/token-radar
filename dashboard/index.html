How implied value is scored

One function scores every protocol from the snapshot's own figures — TVL, 7-day growth, and how long it has run with no token. No protocol name is special-cased.

implied = TVL × size multiple × growth multiplier × age multiplier

An estimate, not a price. It says what a launch would be worth if the protocol's record stayed as it is; it does not predict whether or when a token is issued.

Already trading — the market's own values

These protocols have a token, so the board does not rank them. Their market caps are shown here for comparison, never mixed into the pre-token ranking.

Method: a protocol is pre-token when the snapshot records no market cap, no CoinGecko id and no symbol for it. Wrapped, staked and bridged products of tokens that already trade — bridges, liquid staking, exchanges, versioned pools — are left off the ranked board, because they are not launches waiting to happen. The board covers every protocol on the snapshot's watchlist and every other rankable pre-token protocol in the snapshot.
